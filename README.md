<h2 align="left">About Me</h2>

> "I build experiences that people love." 

Based in **Dhaka, Bangladesh**, I’m a full-stack developer focused on building scalable systems and high-performance applications. I approach code like a craft — with precision, intention, and continuous refinement.

I work across the stack, from application logic to cloud-based backends and data pipelines.  
Recently, I’ve been diving deeper into **AI / ML integration**, building features like recommendation engines, chatbots, and predictive systems.  
My focus is on writing efficient systems and integrating intelligent features (LLMs, Computer Vision) that enhance real-world usability.  
Most days, I’m working with **TypeScript, APIs**, and optimizing data flow and performance.  
I mentor junior developers and occasionally write about AI, backend systems, and modern development workflows.  
I’m currently open to **freelance projects** and select **full-time opportunities**. Let's connect!
